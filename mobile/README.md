# Ứng Dụng Mobile (Flutter)

Mã nguồn cho ứng dụng di động sẽ được đặt tại thư mục này.

**Cách khởi tạo:**
Hệ thống hiện tại chưa nhận diện lệnh `flutter`. Bạn cần cài đặt [Flutter SDK](https://docs.flutter.dev/get-started/install) và cấu hình biến môi trường PATH. 
Sau khi cài đặt xong, hãy mở terminal tại thư mục này (`mobile/`) và chạy lệnh sau để sinh mã nguồn ban đầu:

```bash
flutter create .
```
